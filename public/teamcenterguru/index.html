Block release of a Wdg4_Part revision that has no material.
EPM_decision_t Wdg_check_material(EPM_rule_message_t msg)
{
    int ifail = ITK_ok, n = 0;
    tag_t root = NULLTAG, *targets = NULL;
    EPM_decision_t decision = EPM_go;

    if ((ifail = EPM_ask_root_task(msg.task, &root)) != ITK_ok ||
        (ifail = EPM_ask_attachments(root, EPM_target_attachment,
                                     &n, &targets)) != ITK_ok) {
        EMH_store_error_s1(EMH_severity_error, ifail, "Wdg_check_material");
        return EPM_nogo;
    }
    for (int i = 0; i < n && decision == EPM_go; i++) {
        char *material = NULL;
        ifail = AOM_ask_value_string(targets[i], "wdg4_material", &material);
        if (ifail != ITK_ok || material == NULL || *material == '\0') {
            /* site error text: "A Wdg4 Part revision needs a material" */
            EMH_store_error_s1(EMH_severity_error, WDG_ERR_NO_MATERIAL,
                               "wdg4_material");
            decision = EPM_nogo;
        }
        MEM_free(material);
    }
    MEM_free(targets);
    return decision;
}

The problem

Dev, QA and Production drift apart, and nobody can say exactly how.

A Teamcenter site holds thousands of configuration objects spread over a dozen export formats. TeamcenterGuru compares every area of every environment pair in one run, so the drift is visible at a glance.

Security

Connected to your servers, on your IT team's terms.

TeamcenterGuru reaches Teamcenter through an agent on each server. The agent runs a fixed set of scripts, and your company's IT security installs it, chooses the account it runs as, and can remove it at any time.

TeamcenterGuru Hub names a step, never sends a command

Installed and owned by your IT

The agent is a Windows service on each Teamcenter box, running under the service account your IT team chooses. Uninstalling it revokes its token.

Fixed, predefined scripts

The agent runs only the scripts shipped in its own installer, checked against their manifest before every run. A changed script stops the capture.

No commands from outside

The hub can only name a step, such as a capture; it never sends a command line. The agent connects outward and collects its work in the reply to its own check-in.

Live reads as the signed-in user

Each person signs in to Teamcenter as themselves, by password or SSO, so Teamcenter's own access rules apply. The consultant's live tools only read.

Your choice of AI provider

The consultant works with the AI provider your company approves. Questions and the configuration they need go only to that provider.

Encrypted, isolated, role-based

Saved accounts are stored encrypted. Owner, Admin and Contributor roles are set per environment, and each organization's workspace is isolated.
